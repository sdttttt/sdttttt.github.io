{{- /* Cover image partial - override of PaperMod's cover.html. Why override: PaperMod uses `resources.ByType "image"` to find the cover, which only matches jpg/png/webp/gif - NOT svg. Since our covers are SVGs in `static/`, PaperMod can't find them as a resource, so Hugo doesn't output them to `public/` and the URL 404s. This override: - For files in `static/`: outputs the URL directly (no Hugo processing). Uses `printf` to avoid `absURL` URL-encoding `[` and `]` (so the rendered HTML is clean instead of `%5B%5D`). - For files in `assets/` (e.g. future png/jpg covers): uses `resources.Get` and falls back to PaperMod's responsive image logic. Template: overrides themes/PaperMod/layouts/_partials/cover.html */ -}} {{- with .cxt }} {{- if (and .Params.cover.image (not $.isHidden)) }} {{- end }} {{- end -}}
