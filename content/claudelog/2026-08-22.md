### 完成的工作

- 启用 Hugo 多语言:在 `hugo.toml` 加 `[languages]` 块,简体 `zh`(默认,URL 不带前缀)+ 繁体 `zh-tw`(URL 带 `/zh-tw/`);`defaultContentLanguageInSubdir = false` 让默认语言留在根路径
- 用 `pip install opencc-python-reimplemented` 装到 `.tools/pip/`(sandbox 不让装到 HOME),用 `OpenCC('s2tw')` 把所有内容转繁中台湾标准
- 转换 222 个 `content/posts/*.md` → `*.zh-tw.md`;16 个 `content/claudelog/*.md` → `*.zh-tw.md`;另外 `about.md` / `archives.md` / `search.md` / `posts/_index.md` 也都加了对应 zh-tw 版本
- 每个 zh-tw 文件 front matter 加 `language: "zh-tw"`(Hugo 多语言约定)
- 复制 PaperMod 的 `themes/PaperMod/i18n/zh-tw.yaml` 到本地 `i18n/zh-tw.yaml`(UI 文案:分鐘/字/目錄/上一頁/下一頁/語言 等)
- zh-tw 菜单用中文繁体显示名:文章 / 維護日誌 / 原始碼 / 彙整 / 搜尋 / 標籤 / 關於;`homeInfoParams.Content` 也转繁中(假如我走進海裡, 你會拉住我麼?)
- Hugo 修复 `languageCode` 弃用警告,改用 `locale`(`zh-CN` / `zh-TW`)
- Hugo `--minify` 双语构建通过:ZH 259 页 / ZH-TW 257 页(差 2 个是历史 alias 重定向目录,不重要)
- 已验证生成的 zh-tw HTML 含 `<html lang=zh-tw>`、`og:locale=zh_TW`、`og:description` 是繁体中文、hreflang 双向链接、语言切换器菜单正确显示

### 决策

- 用 `s2tw`(简体→台湾繁体)而不是 `s2t`(仅字符转换):前者同时做用词转换(软件→軟件、网络→網絡、视频→影片、内存→記憶體);后者只转字符会保留大陆用词
- OpenCC 转换覆盖整篇文件(包括 front matter):会把 `title`/`description`/`tags` 等中文值的字符也转;英文字段/URL/代码块不动
- claudelog 也一起转了:虽然不是"文章",但既然公开在站点,双语可读性更一致
- 不动 `defaultContentLanguageInSubdir = false`:保持简体版 URL 不带 `/zh/` 前缀(避免破坏现有 SEO/外链),只有繁体版带 `/zh-tw/`

### 下次建议

- Hugo 0.161 还有 3 个 PaperMod 模板的弃用警告(`LanguageDirection` / `LanguageCode` / `LanguageName`),等 PaperMod 升级时自然解决
- 2 个差量(`20260805-qds` / `20260817-jtc`)是历史 alias 目录只在 zh 出现,不影响正常浏览,可加忽略
- s2tw 自动转换的术语可能在少数地方不准确(如博客自创词、品牌名),需要人工抽查
- OpenCC 对 emoji/英文标点不转换,只动中文字符,所以不会破坏 Markdown 语法
