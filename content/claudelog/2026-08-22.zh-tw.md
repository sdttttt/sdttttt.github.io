## 維護記錄

### 完成的工作

- 啟用 Hugo 多語言:在 `hugo.toml` 加 `[languages]` 塊,簡體 `zh`(默認,URL 不帶前綴)+ 繁體 `zh-tw`(URL 帶 `/zh-tw/`);`defaultContentLanguageInSubdir = false` 讓默認語言留在根路徑
- 用 `pip install opencc-python-reimplemented` 裝到 `.tools/pip/`(sandbox 不讓裝到 HOME),用 `OpenCC('s2tw')` 把所有內容轉繁中臺灣標準
- 轉換 222 個 `content/posts/*.md` → `*.zh-tw.md`;16 個 `content/claudelog/*.md` → `*.zh-tw.md`;另外 `about.md` / `archives.md` / `search.md` / `posts/_index.md` 也都加了對應 zh-tw 版本
- 每個 zh-tw 文件 front matter 加 `language: "zh-tw"`(Hugo 多語言約定)
- 複製 PaperMod 的 `themes/PaperMod/i18n/zh-tw.yaml` 到本地 `i18n/zh-tw.yaml`(UI 文案:分鐘/字/目錄/上一頁/下一頁/語言 等)
- zh-tw 菜單用中文繁體顯示名:文章 / 維護日誌 / 原始碼 / 彙整 / 搜尋 / 標籤 / 關於;`homeInfoParams.Content` 也轉繁中(假如我走進海裡, 你會拉住我麼?)
- Hugo 修復 `languageCode` 棄用警告,改用 `locale`(`zh-CN` / `zh-TW`)
- Hugo `--minify` 雙語構建通過:ZH 259 頁 / ZH-TW 257 頁(差 2 個是歷史 alias 重定向目錄,不重要)
- 已驗證生成的 zh-tw HTML 含 `<html lang=zh-tw>`、`og:locale=zh_TW`、`og:description` 是繁體中文、hreflang 雙向鏈接、語言切換器菜單正確顯示

### 決策

- 用 `s2tw`(簡體→臺灣繁體)而不是 `s2t`(僅字符轉換):前者同時做用詞轉換(軟件→軟件、網絡→網絡、視頻→影片、內存→記憶體);後者只轉字符會保留大陸用詞
- OpenCC 轉換覆蓋整篇文件(包括 front matter):會把 `title`/`description`/`tags` 等中文值的字符也轉;英文字段/URL/代碼塊不動
- claudelog 也一起轉了:雖然不是"文章",但既然公開在站點,雙語可讀性更一致
- 不動 `defaultContentLanguageInSubdir = false`:保持簡體版 URL 不帶 `/zh/` 前綴(避免破壞現有 SEO/外鏈),只有繁體版帶 `/zh-tw/`

### 下次建議

- Hugo 0.161 還有 3 個 PaperMod 模板的棄用警告(`LanguageDirection` / `LanguageCode` / `LanguageName`),等 PaperMod 升級時自然解決
- 2 個差量(`20260805-qds` / `20260817-jtc`)是歷史 alias 目錄只在 zh 出現,不影響正常瀏覽,可加忽略
- s2tw 自動轉換的術語可能在少數地方不準確(如博客自創詞、品牌名),需要人工抽查
- OpenCC 對 emoji/英文標點不轉換,只動中文字符,所以不會破壞 Markdown 語法
