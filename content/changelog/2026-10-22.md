### 遇到的问题

- 宋体细横画在 2px 采样网格上会漏采，3rem 下「边」字明显断续 ⚠️ - 离屏蒙版加 `ink: 0.6` 的 `strokeText`（`lineJoin: round`），并把 `pitchCss` 从 2 调到 1.5；dpr 2 下 step 3 / 边长 2，字形完整且仍看得出颗粒。
- `sin(kx + phase)` 的浪实际向左跑，与验收的「从左滚到右」相反 ⚠️ - 改成 `kx − phase`，并加单测 `ripple_wave_mode_travels_to_the_right` 把方向锁住。
- 最初按墨迹包围盒在画布居中，实测粒子比 DOM 文字高 3.4 CSS px，交叉淡入时文字会往上跳 ⚠️ - 用 `line-height` + `fontBoundingBoxAscent/Descent` 算出与 DOM 相同的基线再落笔，实测墨迹中心差 <0.5 CSS px。
- canvas 是 replaced element：绝对定位下 `left/right + width:auto` 不会撑开，会退回 300×150 固有尺寸 ⚠️ - 显式给 `width: 100%` 与 `height: calc(100% + 1.2rem)`。
- `--screenshot --virtual-time-budget` 下 rAF 与 CSS 过渡都不推进，截到的是「文字尚未淡出」的静态帧，差点误判为粒子没生效 ⚠️ - 改用 CDP 实时驱动（导航 → 等 2.5s → `Page.captureScreenshot` / `Runtime.evaluate`），并读取 `data-pt-title` 与 canvas 像素。
- 用 `deno` 直接跑任务会被本机 mise shim 拦下（未设置全局版本）⚠️ - 用仓库 vendored 的 `.tools/deno/bin/deno`（`bin/lib.sh` 本来就是这么做的）。
