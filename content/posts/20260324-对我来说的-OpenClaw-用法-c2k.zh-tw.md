clawdbot 出來也有一段時間了，這些 AI 項目的迭代速度都很快，這也算是現在是現在 Agent 編碼的優勢吧。

一開始部署這個玩意的時候，我確實不知道該如何使用這個，讓 clawdbot 維護我現有的項目來說，不可控性過高了，我認為不如 Claude Code 之類的其他 Coding Agent。

折騰和運維是我覺得算是最適合 clawdbot 適合去幹的活，例如遷移 blog，維護 github page，編譯 openwrt，搭建項目 Demo 這些，非常適合用 clawdbot 做，專業的領域依然需要用專業的 AI 工具，不過非專業的領域這個工具確實能節約不少時間。
